# Резервное копирование драйверов: руководство

Сохраните драйверы перед переустановкой Windows и затем восстановите их одним нажатием.

## Резервное копирование
1. При запуске читается список сторонних пакетов драйверов (`pnputil /enum-drivers`).
   В столбце **Устройства** показано, какое устройство сейчас использует драйвер.
2. Сузьте список поиском, фильтром класса и опцией «Скрыть драйверы Microsoft».
3. Отметьте нужные и выберите папку для копии в правой панели (например флешку или диск D:).
4. Нажмите **Сохранить**. Каждый драйвер экспортируется в папку `Класс\имя_версия`,
   создаётся файл `drivers_manifest.json`. По желанию создаётся ZIP-архив.

## Восстановление
1. На вкладке **Восстановление** выберите папку с копией или перетащите её в окно.
2. Если есть манифест, показываются имя компьютера, дата и список драйверов. Без манифеста ищутся файлы `.inf`.
3. Отметьте нужные и нажмите **Установить** (`pnputil /add-driver ... /subdirs /install`).
   Для некоторых драйверов потребуется перезагрузка.

## Права администратора
Экспорт и восстановление работают только с правами администратора. Кнопка
**Запустить от имени администратора** в верхней панели перезапускает программу с этими правами.

## Команды
**Показать команды** выводит команды `pnputil`, которые будут выполнены; их можно скопировать
или сохранить в `.bat`. На вкладке **Журнал** сохраняется результат каждой команды.
